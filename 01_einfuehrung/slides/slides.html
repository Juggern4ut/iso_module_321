Was ist ein verteiltes System?

Ein verteiltes System besteht aus mehreren unabhängigen Komponenten, die über ein Netzwerk zusammenarbeiten und für user möglichst wie ein einziges System wirken.

  • Mehrere Programme oder Dienste arbeiten zusammen.
  • Die Teile können auf verschiedenen Rechnern laufen.
  • Die Kommunikation erfolgt über klar definierte Schnittstellen.
  • Ausfälle einzelner Teile müssen mitgedacht werden.

Alltagsbeispiele

  • Online-Shop mit Frontend, Login-Service, Zahlungsdienst und Datenbank
  • Teams oder Slack mit Chat, Dateiablage und Benachrichtigungen
  • Netflix mit vielen Diensten für Benutzer, Empfehlungen und Streaming
  • Schulwebseite mit Webserver, Datenbank und Authentifizierung

Zentrale Begriffe

Cloud-Native

Anwendungen werden so entwickelt, dass sie die Möglichkeiten der Cloud gezielt nutzen: Skalierung, Automatisierung, Container, kurze Deployments.

Zentrale Begriffe

Cloud Functions

Kleine Programmfunktionen laufen ereignisgesteuert in der Cloud. Die Infrastruktur wird vom Anbieter betrieben.

Zentrale Begriffe

XaaS

Anything as a Service: IT-Leistungen werden als Dienst bezogen statt selbst betrieben.

Zentrale Begriffe

Schnittstelle

Eine definierte Art, wie zwei Systemteile Informationen austauschen, zum Beispiel über HTTP oder Messaging.

Cloud-Native genauer

  • Anwendungen sind für Betrieb in der Cloud entworfen.
  • Typisch sind Container, Microservices und automatisierte Deployments.
  • Skalierung kann je nach Last dynamisch erfolgen.
  • Fehler einzelner Komponenten werden erwartet und abgefangen.

Beispiel: Ein Webshop wird in mehreren Diensten betrieben und bei hoher Last automatisch auf weitere Instanzen verteilt.

Cloud Functions genauer

  • Auch bekannt als Function as a Service.
  • Code wird nur ausgeführt, wenn ein Ereignis eintritt.
  • Die Laufzeit ist meist kurz und klar auf eine Aufgabe fokussiert.
  • Serververwaltung entfällt weitgehend für das Entwicklungsteam.

Beispiel: Nach dem Upload eines Bildes wird automatisch eine Funktion gestartet, die eine Vorschau erzeugt.

XaaS genauer

Begriff Bedeutung Beispiel
IaaS Infrastructure as a Service Virtuelle Server
PaaS Platform as a Service Deployment-Plattform
SaaS Software as a Service Microsoft 365, Trello
FaaS Function as a Service AWS Lambda, Azure Functions

XaaS ist der Oberbegriff für diese Dienstmodelle.

Merksätze

  • Verteilte Systeme bestehen aus mehreren zusammenarbeitenden Teilen.
  • Cloud-Native beschreibt, wie Software für die Cloud gebaut wird.
  • Cloud Functions führen kleinen Code ereignisgesteuert aus.
  • XaaS beschreibt IT-Leistungen, die als Dienst bezogen werden.
