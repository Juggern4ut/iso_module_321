Ziel dieser Lektion: Sie können wichtige Grundbegriffe aus dem Bereich verteilte Systeme verstehen, einordnen und mit einfachen Beispielen erklären.

1. Begriffe zuordnen

Erklären Sie die folgenden Begriffe in 1 bis 2 eigenen Sätzen.

Begriff Ihre Erklärung
Verteiltes System
Cloud-Native

XaaS

2. Beispiele erkennen

Ordnen Sie jedem Beispiel den passendsten Begriff zu.

  1. Eine Anwendung besteht aus Web-Frontend, API, Login-Service und Datenbank.
  2. Nach einem Datei-Upload wird automatisch ein kleines Skript gestartet.
  3. Eine Firma nutzt Microsoft 365, ohne die Software selbst zu betreiben.
  4. Eine Anwendung wird so gebaut, dass sie Container, Skalierung und automatische Deployments nutzt.

Verwenden Sie diese Begriffe: Verteiltes System Cloud Functions SaaS / XaaS Cloud-Native

4. Kurzvergleich

Beantworten Sie die Fragen stichwortartig.

  1. Was ist der Hauptunterschied zwischen Cloud-Native und XaaS?
  2. Warum ist ein verteiltes System meist komplexer als ein einzelnes Programm?
  3. Welchen Vorteil haben Cloud Functions in einfachen Worten?

5. Transfer

Denken Sie an eine bekannte Anwendung aus dem Alltag, zum Beispiel Netflix, Spotify, Teams, Instagram oder einen Online-Shop.

Beantworten Sie dazu die folgenden Fragen:

  1. Warum könnte diese Anwendung ein verteiltes System sein?
  2. Wo könnte dort ein XaaS-Angebot genutzt werden?
  3. Wo könnten Cloud Functions sinnvoll eingesetzt werden?
