Lektion 06: Kategorien von Systemkomponenten

Typische Bausteine verteilter Systeme erkennen und fachlich einordnen

Lernziele

  • Ich kann wichtige Kategorien von Systemkomponenten benennen.
  • Ich kann erklären, was Identitätsverwaltung, Ereignisverwaltung, Monitoring, Datenhaltung und Lastenverteilung sind.
  • Ich kann Systemkomponenten zuordnen.
  • Ich kann begründen, warum nicht jede Komponente dieselbe Verantwortung haben darf.
  • Ich kann für einfache Szenarien passende Systemkomponenten auswählen.

Was sind Systemkomponenten?

Systemkomponenten sind Bausteine eines Softwaresystems mit klarer technischer oder fachlicher Verantwortung.

Warum trennen?

  • Verantwortungen werden klarer.
  • Wartung und Austausch werden einfacher.
  • Probleme lassen sich gezielter eingrenzen.
  • Betrieb und Skalierung werden planbarer.

Wichtig

  • Eine Komponente ist nicht einfach nur ein Server.
  • Sie übernimmt eine bestimmte Aufgabe im System.
  • Mehrere Komponenten arbeiten zusammen.
  • Klare Rollen reduzieren unnötige Kopplung.

Identitätsverwaltung

Die Identitätsverwaltung kümmert sich um Benutzer, Anmeldung, Rollen und Zugriffsrechte.

Typische Aufgaben

  • Login und Logout
  • Passwortverwaltung
  • Rollen und Berechtigungen
  • Token oder Sessions ausstellen

Warum separat?

  • Sicherheitslogik ist sensibel.
  • Mehrere Anwendungen können dieselbe Anmeldung nutzen.
  • Rechte sollen zentral verwaltet werden.

Ereignisverwaltung

Ereignisverwaltung verarbeitet oder verteilt Meldungen über eingetretene Zustandsänderungen im System.

Typische Beispiele

  • Bestellung wurde erstellt
  • Zahlung ist eingegangen
  • Datei wurde hochgeladen
  • Benutzer wurde registriert

Nutzen

  • Komponenten werden loser gekoppelt.
  • Mehrere Empfänger können auf ein Ereignis reagieren.
  • Asynchrone Verarbeitung wird einfacher.

Monitoring

Aufgabe

  • Zustand und Verhalten des Systems beobachten
  • Fehler, Ausfälle und Engpässe sichtbar machen
  • Alarme und Trends erkennen

Typische Signale

  • Logs
  • Metriken
  • Fehlerraten
  • Antwortzeiten

Praxisnutzen

  • Probleme werden schneller erkannt.
  • Fehler lassen sich besser eingrenzen.
  • Betrieb wird messbar statt gefühlt.

Datenhaltung

Datenhaltung sorgt dafür, dass Informationen dauerhaft gespeichert, gelesen und konsistent verwaltet werden können.

Typische Formen

  • Relationale Datenbank
  • Dokumentdatenbank
  • Dateispeicher
  • Cache als Ergänzung

Fragen dazu

  • Welche Daten müssen dauerhaft bleiben?
  • Wie wichtig ist Konsistenz?
  • Wie schnell muss gelesen werden?
  • Wer darf welche Daten verändern?

Lastenverteilung

Lastenverteilung verteilt Anfragen oder Arbeit auf mehrere Instanzen, damit das System stabil und schnell bleibt.

Typische Aufgaben

  • Anfragen auf mehrere Server verteilen
  • Ausfälle einzelner Instanzen abfedern
  • Skalierung erleichtern

Wichtige Punkte

  • Health Checks
  • Verteilung nach Regeln
  • Keine einzelne Instanz überlasten

Zusammenspiel im System

Komponente Frage, die sie beantwortet Beispiel

Weitere Komponenten

  • Login-Service
  • Datenbank
  • Monitoring

Betrieb

  • Load Balancer davor
  • Ereignisse bei Uploads
  • Alarme bei Fehlern

Eine reale Anwendung kombiniert oft mehrere dieser Komponenten gleichzeitig.

Typische Fehlannahmen

  • Eine Datenbank ersetzt kein Monitoring.
  • Ein Login-Modul ist nicht automatisch eine vollständige Identitätsverwaltung.
  • Ein Event bedeutet nicht, dass Datenhaltung unwichtig wird.
  • Lastenverteilung löst keine fachlichen Fehler.
  • Mehr Komponenten sind nicht automatisch besser.
Gute Architektur trennt Verantwortungen, ohne unnötig viele Bausteine zu erzeugen.

Merksätze

  • Systemkomponenten haben klar unterscheidbare Aufgaben.
  • Identität, Ereignisse, Beobachtung, Speicherung und Lastverteilung sind verschiedene Verantwortungen.
  • Ein System wird verständlicher, wenn diese Verantwortungen sauber benannt und eingeordnet werden.
  • Die passende Auswahl von Komponenten hängt vom konkreten System ab.

Wichtiger Praxispunkt: erst Verantwortung klären, dann Technik auswählen.
